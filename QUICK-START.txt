📝 PILIH MODE OPERASI:

│  3. Akses: http://127.0.0.1:8000                               │
│                                                                 │
│  ✓ Aplikasi berfungsi 100% normal                              │
│  ✓ Tidak akan error                                            │

│                                                                 │
│  ATAU double-click: START-REVERB.bat                            │
